# Deep Learning Fashion Image Classification

This project uses **Deep Learning and TensorFlow/Keras** to classify fashion product images into 10 categories using the **Fashion MNIST dataset**.

## Categories

T-shirt/Top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle Boot.

## Tools

* Python
* TensorFlow/Keras
* NumPy
* Matplotlib
* Google Colab

## Objective

To build and train a neural network that can identify the category of a fashion product image.
